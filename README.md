# 🍔 Swiggy Delivery Management System – SQL Project

## 📌 Project Overview

The **Swiggy Delivery Management System** is a MySQL-based database project designed to manage and analyze food delivery operations.

The project contains different modules such as **customers, restaurants, menu items, orders, delivery partners, deliveries, payments, and reviews**.

It also includes SQL queries ranging from **beginner-level basic queries to advanced queries** for analyzing the data.

## 🎯 Project Objectives

* Design a structured food delivery database using MySQL.
* Store and manage customer, restaurant, order, and delivery information.
* Perform data retrieval and analysis using SQL queries.
* Understand relationships between different database tables.
* Practice SQL concepts from basic to advanced levels.
* Generate useful insights from the food delivery data.

## 🗂️ Database Tables

The database consists of the following main tables:

* **Customers** – Stores customer details.
* **Restaurants** – Stores restaurant information.
* **MenuCategories** – Stores different food categories.
* **MenuItems** – Stores restaurant menu items and prices.
* **Orders** – Stores customer order details.
* **DeliveryPartners** – Stores delivery partner information.
* **Delivery** – Tracks order delivery details.
* **Payments** – Stores payment information.
* **Reviews** – Stores customer food and delivery reviews.

## 🚀 How to Run the Project

1. Install **MySQL 8.0** or use a MySQL-compatible environment.
2. Create the database using `swiggy_dataset_1.sql`.
3. Run `swiggy_dataset_2.sql` to insert the sample data.
4. Execute the queries from `swiggy_project.sql`.
5. Explore and analyze the results using MySQL Workbench or any MySQL client.
